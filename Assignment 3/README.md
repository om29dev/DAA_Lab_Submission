# Assignment 3: Fractional Knapsack Problem

This folder contains the implementation, test output, and complete documentation for **Assignment No. 3: Emergency Relief Supply Distribution using Fractional Knapsack**.

## Problem Overview

Solve an emergency disaster relief supply distribution problem where a rescue boat with maximum weight capacity $W$ must carry critical supplies (food packets, drinking water, medical kits, infant formula) to flood-affected villages. The **Fractional Knapsack** greedy strategy maximizes total utility value by selecting items based on their value-to-weight ratio ($v_i / w_i$) and allowing partial portions of divisible resources.
